# pazugiri-character-tracker

刀剣乱舞ぱずぎりの育成管理アプリです。ビルドは不要です。

**アプリの URL：** https://mikankaihatu.github.io/pazugiri-character-tracker/

## 使い方

上の URL をブラウザで開くと使えます。
手元で試すときは、`index.html` をブラウザで直接開いてください。

## 機能

- **キャラ一覧**：固定データのキャラを、レア度ごとに一覧表示します。
  - 所持・強化待ち・限界突破・信頼度を記録できます。
  - 所持・刀種・限界突破・奥義色・信頼度・強化待ちで絞り込めます。
- **ドロップ統計**：ステージごとに周回のドロップを記録し、1周平均やドロップ率を集計します。
  - 記録と同時に在庫へ加算できます。記録を削除すると、加算した分も差し引きます。
- **素材トラッキング**：所持キャラごとに育成に必要な素材を登録し、在庫と比べた達成率と不足数を表示します。
  - 全キャラ合計の不足まとめでは、足りない合成素材をレシピの材料に換算します（1段階分）。
- **在庫管理**：素材の所持数を増減します。合成レシピがある素材は、ボタンで合成できます。
- **設定**：ステージとそこで落ちる素材を登録します。
  - データをファイルに書き出したり、ファイルから読み込んだりできます（バックアップ・端末の移行用）。

## キャラ・素材の固定データ

キャラと素材の一覧は画面からではなく、次のファイルで管理します。

| ファイル | 中身 |
| --- | --- |
| `js/master/characters.js` | キャラ（名前・レア度・刀種・奥義色） |
| `js/master/materials.js` | 素材（名前・分類・合成レシピ） |

- 1キャラ・1素材につき1行です。書き方はファイル先頭のコメントを見てください。
- 書き間違い（名前の重複、存在しない素材をレシピに書いた など）があると、画面の上に赤く表示されます。
- 育成状況や在庫は **名前** で保存しています。名前を変えると、その分の記録は引き継がれません。
- JSON ではなく JS ファイルにしているのは、`index.html` を直接開いたときにも読み込めるようにするためです。

## ファイル構成

```
index.html              画面の骨組み（タブとコンテナ）
css/style.css           スタイル
js/master/
  characters.js         キャラの固定データ
  materials.js          素材の固定データ（分類・合成レシピ）
js/data.js              育成状況の保存（localStorage）
js/utils.js             共通の小さな関数（HTML エスケープなど）
js/features/
  characters.js         キャラ一覧タブ（育成状況の編集・フィルター）
  drops.js              ドロップ統計タブ
  materials.js          素材トラッキングタブ
  inventory.js          在庫管理タブ
  settings.js           設定タブ
js/app.js               タブ切り替えと初期化
```

- ビルドは不要です。ファイルを編集して push すれば GitHub Pages に反映されます。
- `index.html` の `<script>` は上から順に読み込まれます。
  - `js/master/` → `data.js` → `utils.js` の順で最初に、`app.js` は最後に読み込んでください。
- 新しいタブを足すときの手順です。
  1. `js/features/` にファイルを作り、`renderXxx()` 関数を書きます。
  2. `index.html` にタブボタン・`<div>`・`<script>` を追加します。
  3. `js/app.js` の `switchTab` に分岐を追加します。

## データの保存先

データはブラウザの `localStorage`（キー名 `toukenData`）に保存されます。
ブラウザや端末が変わるとデータは引き継がれません。
