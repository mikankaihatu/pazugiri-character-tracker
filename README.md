## 使い方

上の URL をブラウザで開くと使えます。

## 機能

- **キャラ一覧**：固定データのキャラを、レア度ごとに一覧表示します。
  - 所持・レベル・レベル上限・信頼度（0〜10）を記録できます。
  - 名前・衣装・所持・刀種・ゆかり・レベル上限・奥義色・信頼度で絞り込めます。
- **ドロップ統計**：ステージごとに周回のドロップを記録し、1周平均やドロップ率を集計します。
  - 章を選んでからステージを選びます。集計も選んでいる章の分だけ表示します。
  - 入力欄には、そのステージで落ちる品が出ます（Excel の「ステージドロップ品」シート）。
  - 記録と同時に在庫へ加算できます（素材のみ）。記録を削除すると、加算した分も差し引きます。
- **素材トラッキング**：所持キャラごとに育成に必要な素材を登録し、在庫と比べた達成率と不足数を表示します。
  - 上限突破の必要素材が Excel にあれば、今のレベル上限から次の上限突破（例：Lv10→20）の素材を自動でセットします。
  - 素材がそろって「上限突破完了」を押すと、在庫から差し引いてレベル上限を上げます。
  - 全キャラ合計の不足まとめでは、在庫で足りない合成素材を、合成レシピをたどって材料まで換算します（何段階でも）。
  - 今の在庫から作れる合成素材には「合成」ボタンが出ます。押すと在庫から1個合成します。
- **在庫管理**：素材の所持数を増減します。合成レシピがある素材は、ボタンで合成できます。
  - 素材トラッキングに登録したキャラの育成に必要な数（📋）と、不足数を素材ごとに表示します。
  - 「育成に必要な素材だけ表示」で、必要な素材だけに絞り込めます。
- **情報の提供**：画面右上の「📝 情報を提供」から [情報提供フォーム](https://docs.google.com/forms/d/e/1FAIpQLSd20NaHxD78ToytsjdwiVBgYvdicYdNh_uqdTjLhYnRM8zObQ/viewform) を開けます。キャラの「編集」画面には、まだ情報がない項目とフォームへのリンクが出ます。
- **不具合の報告**：画面右上の「🐞 不具合を報告」から [報告フォーム](https://forms.gle/P9XydgGZhJAK1Bfn6) を開けます。設定タブの「使用環境をコピー」で、ブラウザなどの情報をフォームに貼れます。
- **設定**：データをファイルに書き出したり、ファイルから読み込んだりできます（バックアップ・端末の移行用）。

## キャラ・素材の固定データ

キャラと素材の一覧は **`data/master.xlsx`** で管理し、変換スクリプトでアプリ用の JS ファイルに変換します。

| シート | 列 |
| --- | --- |
| キャラクター名 | 刀剣男士番号 / 刀剣男士 / 衣装 / レア / 刀種類 / ゆかり / 奥義色 / 奥義数値 / 奥義名 / 奥義lv1〜5説明文 / 1lv〜30lv[体力,攻撃] / 上限突破10→20・20→30・30→35 |
| 素材 | 分類 / 名前 / 入手方法（ドロップ・合成・イベント など） / 効果 |
| 合成レシピ | 名前 / 必要素材,個数（`木の枝1,丸太1,水1` または `[木の枝,1][丸太,1][水,1]` の形） |
| ステージドロップ品 | ステージ名 / 有利刀種（`太刀,打刀` のように複数可） / ドロップ品 / ドロップ品 / …（1行に1ステージ） |

### 更新の手順

1. `data/master.xlsx` を編集して保存します。
2. リポジトリのフォルダで変換スクリプトを実行します。
   ```bash
   python3 -m pip install openpyxl   # 初回だけ
   python3 tools/convert_master.py
   ```
   Windows の場合は `python3` を `python` に読み替えてください。
3. `js/master/` のファイル（characters.js / materials.js / stages.js）が作り直されます。Excel と一緒にコミットしてください。

> **Excel を開く前に必ず `git pull` してください。** Excel は2人が別々に編集すると自動で混ぜられず、どちらかの変更が消えます。

### 書き方のルール

- 一覧の並び順は Excel の行の順です。
- 刀剣男士番号は刀剣男士ごとの番号です。衣装やレアが違っても、同じ刀剣男士には同じ番号を振ります（表示や並び替え、記録の保存には使っていません）。
- 刀剣男士が空の行は読み飛ばします。
- レアの列に何か書いてあれば（`○` など）「レア」、空なら「通常」の見出しに並びます。
- 同じ刀剣男士の別バージョン（軽装など）は、衣装を変えて行を増やします。
- 記録は「刀剣男士-衣装」（レアなら「刀剣男士-衣装-レア」）という名前で保存します。**一度登録した刀剣男士名・衣装名は変えないでください。** 変えると、そのキャラの記録が引き継がれません。
- ゆかりは `夜,天下五剣` のようにカンマ区切りで複数書けます。
- 能力は `740,77`（または `[740,77]`）のように `体力,攻撃` の形で書きます。わかっているレベルだけ埋めれば大丈夫です。
  - 能力の列は、セルの書式を「文字列」にしてあります。書式が「標準」のセルに `1060,140` と入れると、Excel が数値の 1,060,140 に変えてしまうためです。列を増やしたときは、新しい列も書式を「文字列」にしてください。
  - 数値になってしまったセルは、変換スクリプトが「確認してほしいところ」として表示します。
  - 別のシートやサイトからコピーして貼り付けると、セルの書式ごと上書きされて数値になることがあります。貼り付けるときは `[1575,228]` のように `[ ]` で囲むと、書式に関係なく数値になりません。
- 入手方法が「合成」なのに合成レシピがまだない素材は、変換スクリプトが「メモ」として一覧にします（エラーではありません）。
- 素材と個数（合成レシピ・上限突破）は、`黄の絵具1,書き物道具2` のように「素材名＋個数」をカンマ区切りで書きます。`[黄の絵具,1][書き物道具,2]` の形でも読めます。
- 上限突破の列は、わかっている段階だけ埋めれば大丈夫です。
  - 段階が増えたら、`上限突破35→40` のように同じ形の見出しで列を足すと読み込まれます。
- ステージドロップ品シートの品は、素材シートの名前と同じに書きます。素材ではない品は `[絵馬]塩おにぎり` のように先頭に `[種類]` をつけます。
  - 素材ではない品は、ドロップ統計には記録されますが、在庫には入りません。
- 章はステージ名の `-` より前の部分です（`1-4` → 第1章）。`-` のないステージ名は「その他」の章に入ります。
- 書き間違い（名前の重複、赤・青・黄以外の奥義色、存在しない素材をレシピに書いた など）があると、画面の上に赤く表示されます。
- 在庫は **素材名** で保存しています。素材名を変えると、その素材の在庫は引き継がれません。

## ファイル構成

```
index.html              画面の骨組み（タブとコンテナ）
css/style.css           スタイル
data/master.xlsx        キャラ・素材・合成レシピの元データ
tools/convert_master.py master.xlsx → js/master/*.js の変換スクリプト
js/master/
  characters.js         キャラの固定データ（変換スクリプトで作る）
  materials.js          素材の固定データ（変換スクリプトで作る）
  stages.js             ステージと落ちる品の固定データ（変換スクリプトで作る）
js/data.js              育成状況の保存（localStorage）
js/utils.js             共通の小さな関数（HTML エスケープなど）
js/features/
  characters.js         キャラ一覧タブ（育成状況の編集・フィルター）
  drops.js              ドロップ統計タブ
  materials.js          素材トラッキングタブ
  inventory.js          在庫管理タブ
  settings.js           設定タブ（バックアップ）
js/app.js               タブ切り替えと初期化
```

- ビルドは不要です。ファイルを編集して push すれば GitHub Pages に反映されます。
- `index.html` の `<script>` は上から順に読み込まれます。
  - `js/master/` → `data.js` → `utils.js` の順で最初に、`app.js` は最後に読み込んでください。
- 新しいタブを足すときの手順です。
  1. `js/features/` にファイルを作り、`renderXxx()` 関数を書きます。
  2. `index.html` にタブボタン・`<div>`・`<script>` を追加します。
  3. `js/app.js` の `switchTab` に分岐を追加します。

## データの保存先

データはブラウザの `localStorage`（キー名 `toukenData`）に保存されます。
ブラウザや端末が変わるとデータは引き継がれません。
