# pazugiri-character-tracker

刀剣乱舞ぱずぎりの育成管理アプリです。ビルドは不要です。

**アプリの URL：** https://mikankaihatu.github.io/pazugiri-character-tracker/

## 使い方

上の URL をブラウザで開くと使えます。
手元で試すときは、`index.html` をブラウザで直接開いてください。

## 機能

- **キャラ一覧**：固定データのキャラを、レア度ごとに一覧表示します。
  - 所持・強化待ち・限界突破・信頼度を記録できます。
  - 所持・刀種・限界突破・奥義色・信頼度・強化待ちで絞り込めます。
- **ドロップ統計**：ステージごとに周回のドロップを記録し、1周平均やドロップ率を集計します。
  - 記録と同時に在庫へ加算できます。記録を削除すると、加算した分も差し引きます。
- **素材トラッキング**：所持キャラごとに育成に必要な素材を登録し、在庫と比べた達成率と不足数を表示します。
  - 全キャラ合計の不足まとめでは、足りない合成素材をレシピの材料に換算します（1段階分）。
- **在庫管理**：素材の所持数を増減します。合成レシピがある素材は、ボタンで合成できます。
- **設定**：ステージとそこで落ちる素材を登録します。
  - データをファイルに書き出したり、ファイルから読み込んだりできます（バックアップ・端末の移行用）。

## キャラ・素材の固定データ

キャラと素材の一覧は **`data/master.xlsx`** で管理し、変換スクリプトでアプリ用の JS ファイルに変換します。

| シート | 列 |
| --- | --- |
| キャラクター名 | 刀剣男士番号 / 刀剣男士 / 衣装 / レア / 刀種類 / ゆかり / 奥義色(赤,黄,青) / 奥義lv1説明文 / 1lv[体力,攻撃] / 2lv / 3lv |
| 素材 | 分類 / 名前 / 入手方法（ドロップ・合成） |
| 合成レシピ | 名前 / 必要素材,個数（`[木の枝,1][丸太,1][水,1]` の形） |

### 更新の手順

1. `data/master.xlsx` を編集して保存します。
2. リポジトリのフォルダで変換スクリプトを実行します。
   ```bash
   python3 -m pip install openpyxl   # 初回だけ
   python3 tools/convert_master.py
   ```
   Windows の場合は `python3` を `python` に読み替えてください。
3. `js/master/characters.js` と `js/master/materials.js` が作り直されます。Excel と一緒にコミットしてください。

### 書き方のルール

- 一覧の並び順は Excel の行の順です。
- 刀剣男士番号は刀剣男士ごとの番号です。衣装やレアが違っても、同じ刀剣男士には同じ番号を振ります（表示や並び替え、記録の保存には使っていません）。
- 刀剣男士が空の行は読み飛ばします。
- レアの列に何か書いてあれば（`○` など）「レア」、空なら「通常」の見出しに並びます。
- 同じ刀剣男士の別バージョン（軽装など）は、衣装を変えて行を増やします。
- 記録は「刀剣男士-衣装」（レアなら「刀剣男士-衣装-レア」）という名前で保存します。**一度登録した刀剣男士名・衣装名は変えないでください。** 変えると、そのキャラの記録が引き継がれません。
- 能力は `[120,30]` のように `[体力,攻撃]` の形で書きます。
- 入手方法が「ドロップ」の素材が、ドロップ統計の入力欄に出ます。
- 書き間違い（名前の重複、赤・青・黄以外の奥義色、存在しない素材をレシピに書いた など）があると、画面の上に赤く表示されます。
- 在庫は **素材名** で保存しています。素材名を変えると、その素材の在庫は引き継がれません。

## ファイル構成

```
index.html              画面の骨組み（タブとコンテナ）
css/style.css           スタイル
data/master.xlsx        キャラ・素材・合成レシピの元データ
tools/convert_master.py master.xlsx → js/master/*.js の変換スクリプト
js/master/
  characters.js         キャラの固定データ（変換スクリプトで作る）
  materials.js          素材の固定データ（変換スクリプトで作る）
js/data.js              育成状況の保存（localStorage）
js/utils.js             共通の小さな関数（HTML エスケープなど）
js/features/
  characters.js         キャラ一覧タブ（育成状況の編集・フィルター）
  drops.js              ドロップ統計タブ
  materials.js          素材トラッキングタブ
  inventory.js          在庫管理タブ
  settings.js           設定タブ
js/app.js               タブ切り替えと初期化
```

- ビルドは不要です。ファイルを編集して push すれば GitHub Pages に反映されます。
- `index.html` の `<script>` は上から順に読み込まれます。
  - `js/master/` → `data.js` → `utils.js` の順で最初に、`app.js` は最後に読み込んでください。
- 新しいタブを足すときの手順です。
  1. `js/features/` にファイルを作り、`renderXxx()` 関数を書きます。
  2. `index.html` にタブボタン・`<div>`・`<script>` を追加します。
  3. `js/app.js` の `switchTab` に分岐を追加します。

## データの保存先

データはブラウザの `localStorage`（キー名 `toukenData`）に保存されます。
ブラウザや端末が変わるとデータは引き継がれません。
